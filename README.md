# Developer Workforce Extension

Migration repository for Titan Code 3 → 15-agent Developer Workforce.

## Target runtime
- 10 Chat workers in two squads of five
- 2 Work supervisors
- 2 Codex builders
- 1 Codex orchestrator
- ~50 composable specialist profiles

The seed extension is Titan Code 3 v3.0.34. Parallel implementation is divided into four work packages; see AGENTS.md and WORKSTREAMS.md.
